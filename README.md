# pratica-de-JavaScript
exercício de paratcia de JavaScript

# Olá, Mundo! 👋

Projeto simples desenvolvido para praticar os primeiros conceitos de **JavaScript** e interação com elementos de uma página HTML.

## 🚀 Sobre o projeto

A página apresenta uma mensagem inicial e um botão que pode ser utilizado para executar uma ação através do JavaScript.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 📚 Conceitos praticados

- Manipulação do DOM
- Eventos de clique
- Seleção de elementos HTML
- Alteração de conteúdo da página com JavaScript

## 🎯 Objetivo

Este projeto faz parte da minha prática de JavaScript e representa um dos primeiros exercícios de interação entre **HTML, CSS e JavaScript**.
